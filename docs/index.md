# Campus Hub

Moodle の**授業情報**と**授業管理**をまとめた、iPhone / iPad / Mac 用のアプリです。

> **このアプリは三重大学の学生の方向けです。**
> App Store の検索には出ません。案内されたリンクからのみ入手できます。
> 接続先は三重大学の Moodle（`lms-m41.mie-u.ac.jp`）のみで、
> ほかの学校の Moodle のアドレスを入れてもつながりません。

- 時間割に登録した「その日の授業」ごとに、お知らせ・フォーラム・講義資料・締切をまとめて表示します
- 出席と課題をその場で記録し、未提出のものを期限順に並べます
- 休講・補講を読み取って、カレンダーにも入れます
- 出席登録の時間と課題の締切を通知し、知らせた内容はアプリの中で見返せます
- Mac・iPhone・iPad の中身は、ご自分の iCloud でそろいます

## データの扱い

本アプリが通信する相手は、**三重大学の Moodle** と、同期を有効にしている場合の
**ご自分の iCloud** だけです。作者が管理するサーバーはありません。
広告・アクセス解析・行動追跡の仕組みは組み込んでいません。

端末の機能のうち、本アプリが許可を求めるのは次の 3 つです。

| 許可 | 使うところ |
|---|---|
| カレンダー | 休講・補講を、本アプリ専用のカレンダーに登録するため。ほかのカレンダーの予定には触れません |
| カメラ・写真 | 板書や配布物を撮って、授業の記録に残すため。写真アプリには保存せず、本アプリの中に置きます |
| 通知 | 出席登録の時間と課題の締切を知らせるため。通知の中身は端末の中で作ります |

何をどこに保存し、どう消せるかは、[プライバシーポリシー](./privacy)に一覧でまとめています。
利用上の注意は[利用規約](./terms)をご確認ください。

Campus Hub は、三重大学および Moodle の提供元とは関係のない、独立したアプリです。
「Moodle」は Moodle Pty Ltd の登録商標です。

## 困ったときは

| 症状 | 見るところ |
|---|---|
| 休講・補講が出てこない | Moodle のコースの文章・配布された日程表・授業のメモから読み取ります。どこにも書かれていない場合は出ません |
| ほかの端末とそろわない | ［設定］→［iCloud で同期］→「つながるか確かめる」。3 台とも同じ Apple アカウントでサインインしているか確かめてください |
| 通知が来ない | ［設定］→［通知］で許可の状態を確かめてください。出した通知は［通知の履歴］で見返せます |
| 課題が一覧に出てこない | 締め切ってから 14 日は「期限が過ぎています」として残します。まだ開いていない課題は「まだ開いていません」に入ります |
| 「接続できません」と出る | このアプリは三重大学の Moodle 専用です。ほかの学校のサービスに対応する予定は、いまのところありません |
| 学校のアカウントでログインできない | 大学側で「モバイル用の Web サービス」が無効になっている場合があります。総合情報処理センターなどにお問い合わせください |

## 大学の担当者の方へ

本アプリの接続先は `lms-m41.mie-u.ac.jp` のみに限定してあり、
ほかの LMS にはつながりません（アプリ内に書き込んだドメインでのみ動作します）。
Moodle へは公式のモバイル用 Web サービス（`moodle_mobile_app`）を通じて読み取りのみを行い、
Moodle 側のデータへの書き込みや削除は行いません。
使用する API・保存先・通信先は[プライバシーポリシー](./privacy)に記載しています。
追加のご質問は [Discord のサポートサーバー](https://discord.gg/QyT4uA7AUe) へお願いします。
