# Campus Hub プライバシーポリシー

最終改定日：2026年11月10日

Campus Hub（以下「本アプリ」といいます。）の開発者（以下「開発者」といいます。）は、
本アプリにおける利用者の情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます。）を定めます。
本アプリは個人が開発し、提供するものであり、法人は関与していません。

## 第1条（定義）

本ポリシーにおいて使用する用語の意義は、次の各号に定めるところによります。

1. 「利用者」とは、本アプリを利用するすべての者をいいます。
2. 「利用者情報」とは、本アプリの利用に関連して取得され、又は生成される、利用者に関する情報をいいます。
3. 「対応大学」とは、第3条第2項に定める大学をいいます。
4. 「同期フォルダ」とは、複数の端末の間で利用者情報を共有するために、利用者が自ら選択したフォルダをいいます。
5. 「認証トークン」とは、対応大学の Moodle が発行する、利用者の認証に用いる符号をいいます。

## 第2条（基本方針）

1. 開発者は、利用者情報を収集しません。開発者は本アプリのためのサーバーを運営しておらず、
   本アプリから開発者に対して利用者情報が送信されることはありません。
2. 本アプリには、広告の配信、アクセス解析又は行動の追跡（トラッキング）を目的とする機能及び
   外部のソフトウェア開発キット（SDK）を組み込みません。
3. 本アプリは、その機能の提供に必要な範囲に限り、利用者の端末内において利用者情報を取得し、保存します。
   取得する情報及び保存先は、第4条に定めます。

## 第3条（通信先）

1. 本アプリが通信する相手方及び送信する情報は、次の表に定めるとおりとし、本アプリはこれ以外の相手方と通信しません。

   | 通信先 | 目的 | 送信する情報 |
   |---|---|---|
   | 対応大学の Moodle | ログイン、並びに授業情報、お知らせ、フォーラム、課題及び講義資料の取得 | 認証トークン及び取得する情報の指定。ユーザー名及びパスワードによりログインする場合は、入力されたユーザー名及びパスワード |
   | 対応大学の認証ページ（シングルサインオン） | 対応大学のアカウントによるログイン | 認証ページに入力された内容（本アプリを経由せず、認証ページへ直接送信されます。） |
   | 同期フォルダ | 複数の端末の間における利用者情報の共有 | 第4条第1項の表において同期フォルダの欄に ✓ を付した情報 |
   | 開発者のサーバー | **存在しません** | — |

2. 本アプリが接続する Moodle は、次の大学のものに限ります。
   利用者がこれ以外のアドレスを入力した場合であっても、本アプリは接続を行いません。
   - 三重大学（`lms-m41.mie-u.ac.jp`）
   - 立命館大学（`lms.ritsumei.ac.jp`）。ただし、一時的なベータ版として提供します。
3. 対応大学のアカウントによりログインする場合、本アプリは、対応大学が指定する認証ページ
   （立命館大学においては Microsoft のサインインページ）をアプリ内の画面に表示します。
   当該画面に入力された内容は認証ページへ直接送信され、本アプリはパスワードを読み取らず、保存しません。
4. ［マイページ］に掲載するリンク（ユニパ、大学生協、図書館、食堂の献立等）は、
   Safari（大学生協のアプリについては App Store）により開きます。
   本アプリは当該リンク先と通信せず、その内容を取得しません。
   リンク先における情報の取扱いは、各リンク先の定めるところによります。
5. 同期フォルダへの保存は、本アプリにおいては端末内のファイル操作として行います。
   同期フォルダが iCloud Drive 内にある場合、保存されたファイルは Apple Inc. の iCloud により他の端末へ転送されます。
   この場合における情報の取扱いは、[Apple のプライバシーポリシー](https://www.apple.com/jp/legal/privacy/jp/)の定めるところによります。

## 第4条（取り扱う情報及び保存先）

1. 本アプリが取り扱う利用者情報及びその保存先は、次の表に定めるとおりとします。
   同期フォルダの欄に ✓ を付した情報は、利用者が同期を有効にした場合に限り、同期フォルダにも保存します。

   | 情報 | 取得元 | 端末内 | 同期フォルダ | 備考 |
   |---|---|---|---|---|
   | 時間割 | 利用者の入力 | ✓ | ✓ | |
   | 出席及び課題の記録、授業ごとのメモ、点数 | 利用者の入力 | ✓ | ✓ | |
   | 科目の情報（担当教員、教室、単位数、メモ） | 利用者の入力 | ✓ | ✓ | |
   | 手動で追加した授業、曜日の振替 | 利用者の入力 | ✓ | ✓ | |
   | 板書及び配布物の写真 | カメラ、写真ライブラリ | ✓ | ✓ | 画像ファイルを含みます |
   | 本アプリの設定（ノートのリンク先、通知、外観及び表示の設定等） | 利用者の入力 | ✓ | ✓ | |
   | 単位（区分ごとの必要単位数及び修得単位数）、変更したリンク | 利用者の入力（［マイページ］） | ✓ | ✓ | ユニパの内容は取得しません |
   | 端末の名称（「〇〇の iPhone」等） | 端末 | ✓ | ✓ | 同期している端末の一覧の表示に限り使用します |
   | 認証トークン | 対応大学の Moodle | ✓（キーチェーン） | — | 第6条に定めます |
   | 通知の履歴 | 本アプリ | ✓ | — | 端末ごとに保存し、同期しません |
   | Moodle から取得したお知らせ、フォーラム、課題及び講義資料 | 対応大学の Moodle | ✓（一時的な保存） | — | 原本は Moodle に存在します |
   | 休講及び補講の予定 | 本アプリ | ✓（Apple のカレンダー） | — | 第7条に定めます。端末ごとに作成します |

2. 本アプリは、写真を端末の「写真」アプリに保存せず、本アプリ専用の保存領域に保存します。
3. 同期フォルダは利用者が自ら管理するものであり、開発者は、その所在を知り得ず、その内容を閲覧する手段を有しません。

## 第5条（フォルダによる同期）

1. 同期は、利用者が同期フォルダを選択した場合に限り行います。
   利用者が同期フォルダを選択しない限り、利用者情報が端末の外部に保存されることはありません。
2. 利用者は、［設定］→［フォルダで同期］→「フォルダを選ぶ」により同期を開始し、
   同画面の「同期をやめる」によりいつでも同期を停止することができます。
   停止後、本アプリは同期フォルダへの書込みを行いません。ただし、既に保存されたファイルは削除されません（削除の方法は第8条に定めます。）。
3. 同期は、同一の同期フォルダを選択した端末の間においてのみ行われます。
4. 本アプリは、同期フォルダ内に「CampusHub」という名称のフォルダを作成し、
   その内部に限りファイルの作成、変更及び削除を行います。同期フォルダ内のその他のファイルには変更を加えません。

## 第6条（ログイン及び認証トークン）

1. 本アプリは、独自のアカウントを作成しません。ログインは、対応大学の Moodle を通じて行います。
2. ユーザー名及びパスワードによりログインする場合、入力された内容は対応大学の Moodle へ送信され、
   認証トークンの発行に限り使用されます。本アプリは、認証トークンの発行が完了した時点でパスワードを破棄し、保存しません。
3. 認証トークンは、端末のキーチェーン（iOS 及び macOS が備える保護された保存領域）に保存し、
   対応大学の Moodle との通信に限り使用します。
4. 本アプリは、iCloud キーチェーンによる認証トークンの同期を行いません。
   ただし、暗号化されたバックアップからの復元又はクイックスタート等による端末の移行に際し、
   OS の機能により認証トークンが引き継がれる場合があります。
5. 認証トークンは、［設定］→［授業］→「ログアウト」により削除されます。［データを消す］によっては削除されません。
6. 対応大学の Moodle において認証トークンが無効とされた場合、利用者は再度ログインしなければなりません。

## 第7条（端末の機能の利用）

1. 本アプリは、次の表に定める目的及び範囲に限り、端末の機能を利用します。

   | 機能 | 利用目的 | 利用の範囲 |
   |---|---|---|
   | カレンダー | 取得した休講及び補講の予定の登録 | 本アプリが作成する「Campus Hub（休講・補講）」カレンダーに限り、読取り及び書込みを行います。OS の仕様によりフルアクセスの許可を求めますが、他のカレンダーの予定を読み取らず、変更しません |
   | カメラ及び写真 | 板書及び配布物の撮影並びに授業の記録への添付 | 利用者が撮影し、又は選択した画像に限り、本アプリ内に保存します。「写真」アプリへの書込みは行いません |
   | 通知 | 出席登録の時刻及び課題の締切の通知 | 通知の内容は端末内で作成し、外部へ送信しません |

2. 本アプリは、位置情報を取得しません。
3. 利用者は、第1項に定める機能の利用の許可を拒否することができます。
   この場合、当該機能を利用することができなくなるほかは、本アプリの利用に支障を生じません。

## 第8条（利用者情報の削除）

1. 利用者情報の削除の方法は、保存先に応じて次の表に定めるとおりとします。

   | 保存先 | 削除の方法 | 備考 |
   |---|---|---|
   | 端末内（記録、時間割、設定、写真、通知の履歴、マイページの単位及びリンク） | ［設定］→［データを消す］→「この端末の記録」 | 本アプリを削除した場合も削除されます |
   | 同期フォルダ | ［設定］→［データを消す］→「同期フォルダに置いたぶん」 | **他の端末からも削除されます。**削除の対象は同期フォルダ内の「CampusHub」フォルダに限り、同期フォルダ自体及びその他のファイルは削除しません |
   | Apple のカレンダー | ［設定］→［データを消す］→「カレンダーに入れた休講・補講」 | 本アプリが登録した予定に限り削除します |
   | キーチェーン（認証トークン） | ［設定］→［授業］→「ログアウト」 | ［データを消す］によっては削除されません |
   | 対応大学の Moodle | **本アプリによっては削除できません** | 本アプリは Moodle の情報を読み取るのみであり、Moodle のデータを変更せず、削除しません |

2. 本アプリを削除した場合であっても、同期フォルダに保存されたファイル及びカレンダーに登録された予定は削除されません。
   利用者情報をすべて削除する場合、利用者は、本アプリを削除する前に、［データを消す］の三つの項目をすべて実行する必要があります。

## 第9条（第三者への提供）

開発者は利用者情報を取得しないため、利用者情報を第三者に提供することはありません。
第3条第1項に定める通信先への送信は、利用者の操作又は設定に基づき、本アプリの機能の提供に必要な範囲に限り行うものとします。

## 第10条（対象者）

1. 本アプリは、対応大学に在籍する学生が授業のために利用することを目的とします。
2. 本アプリは、13 歳未満の者による利用を想定しておらず、13 歳未満の者の情報を取得することを意図しません。
   本アプリは開発者へ情報を送信しないため、開発者が 13 歳未満の者の情報を保有することはありません。

## 第11条（本ポリシーの変更）

1. 開発者は、必要に応じて本ポリシーを変更することができます。
2. 利用者情報の取扱いの変更を伴わない変更（表現の修正、説明の追加等）は、本ページの最終改定日を更新することにより行います。
3. 取得する情報、保存先、送信先若しくは利用目的の変更又は新たな外部サービスとの連携を伴う変更は、
   変更の内容及び効力発生日を、効力発生日に先立って本アプリの［更新内容］及び本ページに掲示することにより行います。
4. 前項に定める変更を行った場合、開発者は、本アプリ内において利用者に改めて同意を求めます。

## 第12条（本アプリの位置付け）

本アプリは、三重大学、立命館大学及び Moodle の提供元のいずれとも関係を有しない、独立したアプリです。
本アプリは、これらの団体による承認、推奨又は提携を受けたものではありません。
「Moodle」は Moodle Pty Ltd の登録商標であり、本アプリにおいては、対応するサービスを示す目的に限り使用しています。

## 第13条（お問い合わせ）

1. 本ポリシー及び利用者情報の取扱いに関するお問い合わせは、
   [Discord のサポートサーバー](https://discord.gg/QyT4uA7AUe)においてのみ受け付けます。
2. サポートサーバーは他の利用者も閲覧することができるため、利用者は、
   **パスワード、認証トークン、学籍番号その他利用者を識別し得る情報を投稿してはなりません。**
3. 個別の対応を要する場合、開発者は、個別のやり取りに切り替えることがあります。
