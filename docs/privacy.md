# Campus Hub プライバシーポリシー

最終更新：2026年10月26日

このポリシーは、Campus Hub（以下「本アプリ」）が扱うデータについて、
**何を取得し、どこに保存し、どこへ送るのか**を説明するものです。
本アプリは個人が開発・配布しており、法人は関与していません。

## 1. 作者が受け取る情報はありません

本アプリには、**作者が管理するサーバーがありません。**
そのため、利用者の情報が作者のもとに届くことはありません。
広告・アクセス解析（アナリティクス）・行動追跡（トラッキング）の仕組みは組み込んでおらず、
そうした目的の外部ライブラリ（SDK）も一切使っていません。

ただし、「本アプリが何のデータも扱わない」という意味ではありません。
授業情報を表示し、出席や課題を記録するという機能の性質上、本アプリは
利用者の端末の中でさまざまなデータを取得・保存・処理しています。
何をどこに置いているかは、第 2 節と第 3 節に一覧でまとめました。

## 2. 通信する相手

本アプリが通信する相手は、三重大学の Moodle と Apple の iCloud の 2 つだけです。

| 通信する相手 | 目的 | 送るもの |
|---|---|---|
| 三重大学の Moodle（`lms-m41.mie-u.ac.jp`） | 授業情報・お知らせ・フォーラム・課題・講義資料の取得、ログイン | ログイン用のトークン、取得したい情報の指定。ログイン時のみ、入力された ID とパスワード |
| Apple の iCloud（同期を有効にしている場合） | 端末どうしで内容をそろえるため | 第 3 節で「iCloud」と記した項目 |
| 作者のサーバー | **ありません** | — |

本アプリに組み込まれている接続先は三重大学の Moodle のみで、
ほかの学校・事業者のサーバーへは、アドレスを入力してもつながりません。

iCloud は Apple が提供するサービスです。Apple 側でのデータの取り扱いについては、
[Apple のプライバシーポリシー](https://www.apple.com/jp/legal/privacy/jp/)をご確認ください。

## 3. 扱うデータと保存先

「iCloud」の列が ✓ の項目は、同期を有効にしているときに、
**利用者ご自身の iCloud**（CloudKit のプライベートデータベース）に保存されます。

| データ | 取得元 | 端末内 | iCloud | 備考 |
|---|---|---|---|---|
| 時間割 | 利用者の入力 | ✓ | ✓ | |
| 出席・課題の記録、授業ごとのメモ、点数 | 利用者の入力 | ✓ | ✓ | |
| 科目の情報（担当教員・教室・単位数・メモ） | 利用者の入力 | ✓ | ✓ | |
| 手動で追加した授業、曜日の入れ替え | 利用者の入力 | ✓ | ✓ | |
| 板書・配布物の写真 | カメラ・写真ライブラリ | ✓ | ✓ | 画像そのものも iCloud に保存されます |
| アプリの設定（ノートのリンク先など） | 利用者の入力 | ✓ | ✓ | |
| 端末の名前（「〇〇の iPhone」など） | 端末 | ✓ | ✓ | 同期している端末の一覧を設定画面に出すため |
| ログイン用のトークン | Moodle | ✓（キーチェーン） | — | 第 5 節 |
| 通知の履歴 | 本アプリ | ✓ | — | 端末ごとに別で、同期しません |
| Moodle から取得したお知らせ・フォーラム・課題・講義資料 | 三重大学の Moodle | ✓（一時的な控え） | — | 原本は Moodle 側にあります |
| 休講・補講の予定 | 本アプリ | ✓（Apple のカレンダー） | Apple のカレンダー経由 | 第 6 節 |

写真は、端末の**写真アプリには保存しません。**本アプリ専用の保存場所に置きます。

作者は、利用者の iCloud の中身を見ることはできません。
プライベートデータベースは利用者の Apple アカウントに属しており、
開発者はその内容を読み出す手段を持たないためです。

## 4. iCloud での同期について

同期は、端末が iCloud にサインインしている場合、**初期状態で有効**です。
［設定］→［iCloud で同期］から、いつでも切ることができます。

- 同期を**切った**場合：データは端末の中だけに残り、以後 iCloud へは送られません。すでに iCloud にあるぶんは残ります（消し方は第 7 節）
- 同期を**入れた**場合：第 3 節で ✓ を付けた項目が、同じ Apple アカウントでサインインしたほかの端末とそろいます

同期の可否は、Apple アカウントの状態や iCloud の空き容量に左右されます。
うまくいかないときは、［設定］→［iCloud で同期］→「つながるか確かめる」で状態を確認できます。

## 5. 三重大学 Moodle へのログインと認証トークン

ログインは三重大学の Moodle 上で行われ、本アプリ独自のアカウントは作りません。

ログイン方法として ID とパスワードを入力した場合、入力された値は
**三重大学の Moodle へ送られ、ログイン用のトークンと引き換えられます。**
パスワードは、引き換えが済んだ時点で破棄し、保存しません。

受け取ったトークンは、その端末のキーチェーン（iOS / macOS が持つ保管庫）に保存し、
以後の Moodle への問い合わせに使います。トークンについては、次の点にご注意ください。

- **iCloud キーチェーンによる同期は使っていません。**本アプリが iCloud 経由でトークンをほかの端末へ渡すことはありません
- ただし、端末の暗号化バックアップからの復元や、端末の引き継ぎ（クイックスタートなど）では、OS の仕組みによってトークンが移ることがあります
- トークンは、［設定］→［授業］→「ログアウト」で削除されます。［データを消す］では削除されません（第 7 節）
- Moodle 側でトークンが失効した場合は、再度ログインが必要になります

## 6. 端末の機能を使うところ

| 許可 | 使うところ | 範囲 |
|---|---|---|
| カレンダー | 読み取った休講・補講を予定として登録するため | 本アプリが作る「Campus Hub（休講・補講）」という専用カレンダーのみを読み書きします。OS の仕様上、許可は「フルアクセス」を求めますが、ほかのカレンダーの予定を読み取ることも、書き換えることもしません |
| カメラ・写真 | 板書や配布物を撮って、その回の授業の記録に残すため | 撮影・選択した画像だけを本アプリ内に保存します。写真アプリへの書き込みは行いません |
| 通知 | 出席登録の時間や課題の締切を知らせるため | 通知の内容は端末の中で作っており、外部に送ることはありません |

いずれの許可も、使わなければ断ったままで構いません。
その機能が使えなくなるだけで、ほかの機能は従来どおり動きます。

## 7. データの削除方法

保存先ごとに消し方が異なります。

| 保存先 | 消し方 | 補足 |
|---|---|---|
| 端末の中（記録・時間割・設定・写真・通知の履歴） | ［設定］→［データを消す］→「この端末の記録」 | アプリを削除した場合も消えます |
| iCloud | ［設定］→［データを消す］→「iCloud に置いたぶん」 | **ほかの端末からも消えます。**［設定］→［Apple アカウント］→［iCloud］からも消せます |
| Apple のカレンダー | ［設定］→［データを消す］→「カレンダーに入れた休講・補講」 | 本アプリが登録した予定のみを消します |
| キーチェーン（ログイン用のトークン） | ［設定］→［授業］→「ログアウト」 | ［データを消す］では消えません |
| 三重大学の Moodle | **本アプリからは消せません** | 課題・お知らせ・提出物などの原本は Moodle 側にあります。本アプリは読み取っているだけで、Moodle のデータに書き込みも削除も行いません |

アプリを削除しただけでは、iCloud に入ったぶんと、
カレンダーに登録された予定は残ります。完全に消したい場合は、
アプリを削除する**前に**［データを消す］で 3 つとも消してください。

## 8. 対象年齢について

本アプリは、三重大学に在学する方が授業で使うことを想定しています。
13 歳未満の方の利用は想定しておらず、13 歳未満の方から情報を得ることを意図していません。

本アプリは作者のサーバーに情報を送らないため、作者が 13 歳未満の方の情報を
保有することはありませんが、もしお気づきの点があれば第 11 節の窓口へご連絡ください。

## 9. このポリシーの変更

変更の内容に応じて、次のようにお知らせします。

| 変更の種類 | お知らせの方法 |
|---|---|
| 表現の調整、説明の追記など、取り扱いが変わらないもの | このページの「最終更新」を改めます |
| 取得するデータ、保存先、送信先、利用目的が変わるもの | **変更の内容と適用の時期**を、アプリの［更新内容］とこのページに明記します |
| 新たな外部サービスとの連携を始めるもの | 同上。連携先と、送るデータの範囲を明記します |

## 10. 独立したアプリであること

Campus Hub は、三重大学および Moodle の提供元とは関係のない、独立したアプリです。
提供元から承認・推奨・提携を受けたものではありません。
「Moodle」は Moodle Pty Ltd の登録商標で、本アプリでは対応していることを示す目的でのみ用います。
