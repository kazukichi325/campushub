# Campus Hub 利用規約

最終更新：2026年10月26日

この規約は、Campus Hub（以下「本アプリ」）の利用について定めるものです。
本アプリは個人が開発・配布しており、法人は関与していません。以下「作者」といいます。

App Store で配信されるアプリには Apple の標準使用許諾契約
（[Licensed Application End User License Agreement](https://www.apple.com/legal/internet-services/itunes/dev/stdeula/)）
が適用され、この規約はそれを補うものです。食い違う部分は Apple の契約が優先します。

## 1. 本アプリでできること

本アプリは、利用者ご自身が持つ**三重大学の Moodle のアカウント**で三重大学の Moodle に接続し、
授業情報・お知らせ・フォーラム・講義資料・課題を取得して、表示・整理するための道具です。
あわせて、出席や課題の記録、授業ごとのメモや写真の保存を、利用者ご自身の端末の中で行います。

接続先は三重大学の Moodle（`lms-m41.mie-u.ac.jp`）のみがアプリ内に書き込まれており、
ほかの学校・事業者の LMS のアドレスを入力してもつながりません。
ほかのサービスへ対応する予定は、いまのところありません。

## 2. 独立したアプリであること

**本アプリは、三重大学および Moodle の提供元とも関係のない、独立したアプリです。**
提供元から承認・推奨・提携を受けたものではありません。
「Moodle」は Moodle Pty Ltd の登録商標で、本アプリでは対応していることを示す目的でのみ用います。

## 3. 利用者ご自身の責任で確かめていただくこと

### 3-1. 学校の規則

三重大学の Moodle を第三者のアプリから利用してよいかは、**大学の規則によります。**
利用の前に、情報セキュリティポリシーや Moodle の利用規程を確かめ、
必要であれば総合情報処理センターにお問い合わせください。
規則に反した利用によって生じた不利益について、作者は責任を負いません。

### 3-2. 表示される内容の正確さ

休講・補講の読み取りは、Moodle に書かれた文章からの**自動判定**です。
取りこぼしや誤りがあります。また、締切や課題の表示は、Moodle から取得した時点の
内容にもとづくため、その後の変更が反映されていないことがあります。

**大切な連絡や締切は、かならず Moodle の原文でお確かめください。**
本アプリの表示のみを頼りにしたことで生じた不利益（授業の受け損ない、課題の出し忘れ、
出席登録の漏れなど）について、作者は責任を負いません。

### 3-3. 通知

通知は、OS の状態・電波・省電力の設定などによって、遅れたり届かなかったりします。
通知が届くことを前提にした使い方はお控えください。

## 4. 禁止すること

- 他人のアカウントで接続すること、自分のアカウントを他人に使わせること
- Moodle に過大な負荷をかける使い方（短い間隔での繰り返しの取得など）
- 本アプリを改変したものを配布すること、および本アプリの複製を再配布すること
- 本アプリの解析や改変のうち、**法令により認められている範囲を超えるもの**

  認められている行為を禁止するものではありません）
- 法令または三重大学の規則に反する目的での利用

変更の内容に応じて、次のようにお知らせします。

その場合も、分かった時点でアプリの［更新内容］とこのページでお知らせします。
