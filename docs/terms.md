# Campus Hub 利用規約

最終改定日：2026年11月10日

この利用規約（以下「本規約」といいます。）は、Campus Hub（以下「本アプリ」といいます。）の開発者（以下「開発者」といいます。）が提供する
本アプリの利用条件を定めるものです。本アプリは個人が開発し、提供するものであり、法人は関与していません。

## 第1条（適用及び同意）

1. 本規約は、本アプリの利用に関する開発者と利用者との間の一切の関係に適用されます。
2. 利用者は、本規約及び[プライバシーポリシー](./privacy)（以下「プライバシーポリシー」といいます。）に同意した場合に限り、
   本アプリを利用することができます。
3. 利用者は、本アプリ内に表示される同意画面において同意の操作を行った時点で、本規約及びプライバシーポリシーに同意したものとみなします。
4. App Store を通じて配信される本アプリには、Apple の標準使用許諾契約
   （[Licensed Application End User License Agreement](https://www.apple.com/legal/internet-services/itunes/dev/stdeula/)）が適用されます。
   本規約は同契約を補完するものとし、両者の定めが抵触する場合は、同契約の定めが優先します。

## 第2条（定義）

本規約において使用する用語の意義は、次の各号に定めるところによります。

1. 「利用者」とは、本アプリを利用するすべての者をいいます。
2. 「対応大学」とは、第3条第2項に定める大学をいいます。
3. 「Moodle 情報」とは、本アプリが対応大学の Moodle から取得する授業情報、お知らせ、フォーラム、講義資料、課題その他の情報をいいます。

## 第3条（本アプリの内容）

1. 本アプリは、利用者が自己の対応大学のアカウントにより対応大学の Moodle に接続し、
   Moodle 情報を取得して表示及び整理するためのアプリです。
   利用者は、本アプリにより、出席及び課題の記録並びに授業ごとのメモ及び写真の保存を、自己の端末内において行うことができます。
2. 本アプリが接続する Moodle は、次の大学のものに限ります。
   利用者がこれ以外のアドレスを入力した場合であっても、本アプリは接続を行いません。
   - 三重大学（`lms-m41.mie-u.ac.jp`）
   - 立命館大学（`lms.ritsumei.ac.jp`）。ただし、一時的なベータ版として提供します。
3. 開発者は、前項に定めるベータ版の内容を、利用者に予告することなく変更し、又はその提供を終了することができます。
4. 開発者は、現時点において、対応大学以外の大学又はサービスに対応する予定を有しません。

## 第4条（本アプリの位置付け）

**本アプリは、三重大学、立命館大学及び Moodle の提供元のいずれとも関係を有しない、独立したアプリです。**
本アプリは、これらの団体による承認、推奨又は提携を受けたものではありません。
「Moodle」は Moodle Pty Ltd の登録商標であり、本アプリにおいては、対応するサービスを示す目的に限り使用しています。

## 第5条（利用者の責任）

1. 第三者のアプリにより対応大学の Moodle を利用することの可否は、**各対応大学の規則の定めるところによります。**
   利用者は、本アプリの利用を開始する前に、自己の責任において、所属する対応大学の情報セキュリティポリシー、
   Moodle の利用規程その他の規則を確認し、必要に応じて対応大学の担当部署に問い合わせたうえ、これらを遵守しなければなりません。
2. 休講、補講及び試験の情報は、Moodle に掲載された文章に基づき**自動で判定したもの**であり、見落とし又は誤りを含む場合があります。
   また、締切及び課題の表示は Moodle 情報を取得した時点の内容に基づくものであり、その後の変更が反映されていない場合があります。
   **利用者は、重要な連絡及び締切を、必ず Moodle の原文により確認しなければなりません。**
3. 通知は、端末の状態、通信環境、省電力の設定等により、遅延し、又は到達しない場合があります。
   利用者は、通知が確実に到達することを前提として本アプリを利用してはなりません。
4. 利用者は、自己の対応大学のアカウント及び端末を、自己の責任において管理するものとします。

## 第6条（禁止事項）

利用者は、本アプリの利用に当たり、次の各号に掲げる行為をしてはなりません。

1. 他人のアカウントにより接続し、又は自己のアカウントを他人に使用させる行為
2. 短い間隔で繰り返し情報を取得する等、対応大学の Moodle に過大な負荷を与える行為
3. 本アプリを改変したもの又は本アプリの複製物を頒布する行為
4. 本アプリの解析又は改変のうち、**法令により認められる範囲を超えるもの**
   （相互運用性の確保、不具合の調査、研究等を目的とする解析であって、
   著作権法その他の法令により認められる行為を禁止するものではありません。）
5. 法令、公序良俗又は対応大学の規則に違反する行為
6. 前各号に掲げるもののほか、開発者が不適切であると合理的に判断する行為
